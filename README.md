# EchoScript Voice - Native Android App (Kotlin & Jetpack Compose)

این پروژه سورس‌کد کامل و استاندارد نسخه اندروید اپلیکیشن **EchoScript Voice** با زبان **Kotlin**، فریم‌ورک **Jetpack Compose** و معماری مدرن **Material 3** است.

---

## 🚀 راهنمای سریع و ۳ روش ساخت فایل نصبی APK:

### روش ۱: اجرای اسکریپت خودکار ۱-کلیکی (سریع‌ترین روش)
- **کاربران ویندوز:** فقط روی فایل `build-apk.bat` دوبار کلیک کنید. فرآیند بیلد شروع شده و پس از پایان، پوشه حاوی فایل `app-debug.apk` خودکار باز می‌شود.
- **کاربران مک و لینوکس:** ترمینال را در پوشه باز کرده و دستور زیر را اجرا کنید:
  ```bash
  bash build-apk.sh
  ```

### روش ۲: ساخت آنلاین و ابری بدون نیاز به هیچ نرم‌افزاری (GitHub Actions)
1. این پروژه را در حساب **GitHub** خود به صورت یک مخزن (Repository) آپلود (Push) کنید.
2. به تب **Actions** بروید؛ مشاهده می‌کنید که ساخت فایل APK به صورت خودکار شروع شده است.
3. پس از حدود ۲ دقیقه، در بخش **Artifacts** می‌توانید فایل `EchoScript-Voice-Debug-APK.zip` را دانلود کرده و فایل `app-debug.apk` را مستقیماً روی گوشی نصب کنید.

### روش ۳: باز کردن در Android Studio
1. نرم‌افزار **Android Studio** را باز کنید و گزینه **Open Project** را بزنید و پوشه پروژه را انتخاب کنید.
2. اجازه دهید فرآیند **Gradle Sync** انجام شود.
3. برای ساخت APK:
   - از منوی بالا: **Build > Build Bundle(s) / APK(s) > Build APK(s)**
   - یا در تب Terminal:
     ```bash
     ./gradlew assembleDebug
     ```
4. فایل خروجی نصبی در این مسیر قرار دارد:
   `app/build/outputs/apk/debug/app-debug.apk`

## 📱 قابلیت‌های نسخه اندروید:
1. **تبدیل گفتار به متن (Voice-to-Text):** پشتیبانی کامل و بومی از زبان فارسی (`fa-IR`) و انگلیسی با موتور قدرتمند `SpeechRecognizer` اندروید بدون نیاز به تایپ.
2. **دکمه شناور روی تمامی برنامه‌ها (Floating Bubble Window):** یک حباب میکروفون شناور که روی هر برنامه‌ای (تلگرام، واتساپ، ChatGPT، اینستاگرام، مرورگر کروم و نوت‌گوشی) قرار می‌گیرد و با یک لمس صدا را ضبط کرده، پرامپت را می‌سازد و کپی یا تایپ می‌کند.
3. **ترجمه هوشمند یک‌کلیکی (1-Tap Translate):** تبدیل سریع متن فارسی به انگلیسی و برعکس با یک لمس.
4. **مهندسی و ارتقای پرامپت هوش مصنوعی (Prompt Professionalizer):** تبدیل ایده صوتی به پرامپت ساختاریافته هوش مصنوعی.
5. **طراحی Touch-Friendly و مدرن:** مناسب انواع گوشی‌های اندروید با تم تاریک و روشن خودکار و انیمیشن‌های روان.
